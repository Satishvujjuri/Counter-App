# 🧮 Counter App

A simple and interactive Counter App built using **HTML, CSS, and JavaScript**.

This project allows users to increase, decrease, and reset a counter. It also includes additional features such as keyboard controls, light/dark theme switching, an information modal, animations, and theme persistence using Local Storage.

## 🚀 Features

- ➕ Increase the counter
- ➖ Decrease the counter
- 🔄 Reset the counter
- ⌨️ Keyboard shortcuts
  - `Arrow Up` → Increase
  - `Arrow Down` → Decrease
  - `R` → Reset
- 🌙 Light/Dark theme toggle
- 💾 Saves selected theme using Local Storage
- ℹ️ Information modal
- 🎨 Smooth animations and hover effects
- 📱 Responsive layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
